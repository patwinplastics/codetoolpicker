Same Model, Different Harness: Copilot CLI vs Claude Code vs Codex CLI

TL;DR · 🥊 Head-to-head

🏆 Pick the model, not the harness

Read the full short answer

Short answer: on GitHub's new Harnesses view, putting the same model in a different agent barely changes how many tasks get solved. In 20 of 21 matched pairs the gap was 4 points or less. What changes is the bill. With Claude models, Copilot CLI usually cost more per task than Claude Code (7% to 21% more in 6 of 9 pairs). With GPT models, Copilot CLI cost less than Codex CLI in 11 of 12 pairs (2% to 55% less).

So the model you pick still decides most of the result. The harness is a cost and workflow choice. And keep in mind who ran the test: GitHub, on its own product, with Codex CLI's costs estimated from API prices.

Checked Nov 24, 2026 on the GitHub Copilot benchmarks site (Harnesses view, data archive dated Nov 16, 2026, marked public preview), GitHub's Nov 17 changelog, GitHub's June 25 harness evaluation post, and GitHub Copilot plans for AI credit allowances.

What GitHub actually measured
  • Same model, same effort. GitHub's changelog says the view "compares GitHub Copilot CLI with Claude Code and Codex CLI using the same model at the same reasoning effort." Only exact model pairs at medium reasoning effort are shown. Copilot-only setups like Copilot Fusion are left out.
  • Copilot CLI vs the model maker's own agent. Claude models are compared with Claude Code; OpenAI models with Codex CLI. There is no Claude Code vs Codex CLI pairing, because they never run the same model.
  • Three benchmarks: DeepSWE 1.1 (113 tasks), Terminal-Bench 4.0 (66 tasks) and the new Terminal-Bench-Science 0.1 (70 research tasks). Each setup ran 3 to 5 times; the numbers are averages.
  • Two numbers per result: resolution rate (share of tasks solved) and mean cost per task in USD at list token prices.
  • Versions tested: Copilot CLI 1.0.105 to 1.0.112, Claude Code 2.1.317 to 2.1.325, Codex CLI 0.166.0 to 0.169.0.
  • Codex CLI costs are estimates. GitHub's notes say Codex CLI "logs token usage but not cost," so its costs are estimated from OpenAI's public API prices at standard short-context rates, and "actual billed amounts may differ."

What it means for you
  • Model first, harness second. Going from Claude Haiku 5.5 to Opus 5.5 inside the same harness moved DeepSWE scores by about 16 points. Switching harness on the same model moved them by 3.5 points at most, except GPT-6 Luna.
  • Claude Code is the cheaper home for Claude models, mostly. Copilot CLI solved a few more DeepSWE tasks with every Claude model (intervals above zero for Opus and Sonnet), but cost 7% to 21% more per task in 6 of 9 Claude pairs. The big exception: Opus 5.5 on Terminal-Bench-Science, where Copilot CLI was 21% cheaper ($6.64 vs $8.40).
  • Copilot CLI looks cheaper than Codex CLI for GPT models, with scores within a few points. Biggest gaps: GPT-6.1 Terra was 26% cheaper on Terminal-Bench 4.0 and 51% cheaper on Terminal-Bench-Science (but 3.4 points lower there, a tie within noise). Remember Codex costs are GitHub's estimates.
  • GPT-6 Luna is the odd one. On DeepSWE 1.1, Copilot CLI solved 49.4% vs Codex CLI's 36.6% (12.7 points, the only large gap), at 47% higher cost ($0.08 vs $0.06 a task). Cheap either way.
  • On a flat plan, cost per task means limits, not dollars. If you pay for Claude Pro or Max or ChatGPT Plus or Pro, a cheaper harness doesn't lower your bill. It may stretch your usage limits, if the plan meters roughly by tokens. On Copilot (AI credits at $0.01 each) or an API key, cost per task is real money.
  • The cheapest move is often a smaller model. GPT-6.1 Terra in Copilot CLI solved 69.0% of DeepSWE at $0.28 a task. Claude Opus 5.5 solved 72.0% at $1.65. That's about 6x the cost for 3 more points.

Caveats worth reading
  • GitHub graded its own product. We haven't seen a matching harness comparison from Anthropic or OpenAI. GitHub's own June write-up called the results "effective parity" because most gaps sit inside run-to-run noise.
  • Medium effort only. Most people run Opus or Astra at high or max effort for hard work. Gaps at other effort levels aren't published.
  • Benchmarks run single-turn and unattended. In GitHub's June methodology, agents ran non-interactively with web tools off. Your day-to-day use, with plan mode, follow-ups and reviews, can behave differently.
  • Codex CLI costs are estimated at OpenAI's standard short-context API prices, excluding long-context price bands, per GitHub's notes.
  • The data is marked provisional and in public preview, and agent versions keep changing. Copilot CLI shipped several versions during the test window.
  • Older model versions. GitHub tested GPT-6 Astra and GPT-6.1 Sol, not GPT-6.2. Gemini models aren't in the harness view.

What we couldn't confirm
  • The exact intervals GitHub shows. We recomputed them from the per-run data embedded in GitHub's site with the same method. They should match closely, but we did not compare every bar by eye.
  • How these costs map to subscription limits. Anthropic and OpenAI don't publish how many tokens a Claude or ChatGPT plan includes, so "cheaper per task" can't be turned into "X more tasks per week" on those plans.
  • Higher effort results. GitHub publishes high and max effort scores for Copilot CLI, but not matched against Claude Code or Codex CLI.

FAQ

4 questions

Is Copilot CLI better than Claude Code with the same model?

On GitHub's own benchmark site (Nov 17, 2026 data), Copilot CLI solved slightly more tasks than Claude Code with Claude Opus, Sonnet and Haiku 5.5 on DeepSWE 1.1 (about 3 to 3.5 points), but on Terminal-Bench 4.0 the scores were within noise. Copilot CLI cost the same per task with Opus 5.5 on DeepSWE and 7% to 21% more in 6 of the other 8 Claude pairs. GitHub ran the test on its own product, so treat it as one data point.

Is Copilot CLI cheaper than Codex CLI with the same GPT model?

In 11 of 12 GPT pairs on GitHub's benchmark site, Copilot CLI had a lower cost per task than Codex CLI, from 2% to 55% lower, while resolution rates stayed within a few points. The exception was GPT-6 Luna on DeepSWE 1.1, where Copilot CLI solved 12.7 points more but cost 47% more. GitHub says Codex CLI does not log cost, so its costs are GitHub's estimates from OpenAI's public API prices.

Does the harness matter more than the model?

Not for the score. In GitHub's 21 matched pairs, switching harness moved resolution by 4 points or less in 20 of them, while switching between the models GitHub tested moved it by up to about 55 points (Claude Haiku 5.5 to Opus 5.5 alone is about 16 points on DeepSWE 1.1). The harness mattered more for cost: the same model cost up to 85% less or 47% more per task depending on the harness.

Do these costs apply if I pay for Claude Pro, Max or ChatGPT Plus?

Not directly. The costs are list-price token costs per task. On a flat subscription you pay the same monthly price either way, so a cheaper harness means your usage limits last longer, not a smaller bill. On GitHub Copilot, where usage is billed in AI credits at $0.01 each, and on API keys, cost per task maps to real money.
