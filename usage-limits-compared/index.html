AI coding tool usage limits and real cost per task (Oct 2026)

Short answer: the six big AI coding tools meter you in four different ways. Claude Code, OpenAI Codex (Plus) and Google Antigravity (AI Pro) use a rolling five-hour window plus a weekly cap. Cursor gives you one weekly pool. GitHub Copilot gives you a monthly budget of AI credits worth $0.01 each. Gemini CLI on a Code Assist license has a daily request quota. Only GitHub publishes the allowance in dollars and only OpenAI publishes message ranges; Anthropic, Google (for Antigravity) and Cursor publish the reset rhythm but not the size. Once you go past the limit, almost everyone bills extra usage at the model's API price, so a medium agent task costs roughly the same $0.70 on Sonnet 5.5, GPT-6.1 Sol or Gemini 4 Argon wherever you run it (our estimate, assumptions below).

Last verified Oct 23, 2026 on each vendor's official pricing pages and docs (Artificial Analysis cost check and Antigravity Argon quota added Oct 29) (sources under every table). Limits change often; confirm with the linked sources before you buy.

Which reset rhythm fits how you work

  • You code in bursts every day: five-hour windows (Claude Pro, Codex Plus, Antigravity on Google AI Pro) suit you. Hit the wall, take a break, come back. The weekly cap is what stops all-day, every-day use.
  • You have a few heavy days a week: Cursor's weekly pool lets you burn most of it on Tuesday. One heavy day can't take your whole month, but it can take your week.
  • You want a dollar number: GitHub Copilot is the only one that tells you exactly what you get ($15 of usage on Pro, $70 on Pro+, $200 on Max). The catch: it resets once a month, so a big first week can leave you dry until the 1st. And a third of Pro's credits are "flex," which GitHub says can change "as the economics of AI evolve."
  • You're on a company license: Code Assist's 1,500 or 2,000 requests a day is the most predictable quota here, but it counts requests, not tokens, and Google hasn't said what happens when you run out.

Reality check: what hard tasks cost on a benchmark

Artificial Analysis's Coding Agent Index measures real cost per task at API prices, including cache writes. On its 290 hard tasks (checked Oct 29, 2026), Claude Code with Opus 5.5 averaged $11.42 a task, Claude Code with Sonnet 5.5 $13.30, Antigravity CLI with Gemini 4 Argon $11.73, Codex with GPT-6 Astra $7.04 and Codex with GPT-6.1 Sol $1.50.

That's not a contradiction of the table above. Those tasks are much bigger than our "medium": Claude Code with Opus 5.5 averaged 14.5M tokens, 146 turns and an hour per task at max effort, about 10 times our medium task. Per token it's close to our math: $0.79 per million tokens measured vs $0.90 in our Opus estimate (they saw 95% of input cached; we assume 90%). So read our Small to Large rows as everyday work, and expect $1.50 to $13 at API prices for a hard, hour-long task. Full breakdown: what one AI coding task really costs.

What that means for each plan Estimate

  • Copilot Pro ($10, 1,500 credits): about 22 medium tasks a month on Claude Sonnet 5.5 (68.5 credits each). Opus 5.5 isn't on Pro.
  • Copilot Pro+ ($39, 7,000 credits): about 51 medium Opus 5.5 tasks, or about 100 on Sonnet 5.5. Max ($100, 20,000 credits): about 146 on Opus.
  • Claude Code: Anthropic says the average enterprise cost is about $13 per developer per active day and 90% of users stay under $30. On our assumptions, $13 is about 19 medium Sonnet tasks or 9 on Opus. Past your Pro or Max limit, usage credits bill at these API rates.
  • Codex: OpenAI says "a typical GPT-5.6 Sol task may use 2-15 credits," but it doesn't publish one price for credits, so we can't turn that into dollars. On an API key, GPT-6.1 Sol costs the same as Sonnet 5.5 on our assumptions.
  • Cursor: Grok 4.7 has a cheaper output price than Sonnet 5.5, but its cache reads cost 5x as much ($0.50 vs $0.10), so in long, cache-heavy agent loops it comes out about 60% more expensive per task. It's inside your weekly pool, so you feel it as hitting the pool sooner, not as a bill.
  • Antigravity: Gemini 4 Argon is the same price as Sonnet 5.5 until Nov 30, then doubles to Opus 5.5 pricing on Dec 1. If you pay for Google AI credit overages, expect the same per-task cost to double.

The honest takeaway: past the limit, the same model costs about the same everywhere. What you're really comparing is how big the included allowance is and how often it refills, and only GitHub and OpenAI put numbers on that.

How to stretch your limits

Everywhere

  • Start a fresh session for each task. Every turn resends the whole conversation, so a long, unrelated history is the biggest hidden cost.
  • Use the cheaper model for easy work. Opus 5.5 costs 2x Sonnet 5.5 per task on our estimate; Gemini 3.8 Flash and GPT-6 Luna cost a fraction.
  • Keep instruction files short. CLAUDE.md, AGENTS.md and GEMINI.md load into every request.
  • Turn off MCP servers you aren't using. Their tool definitions take up context on every turn.
  • Be specific. "Fix the null check in auth.ts line 40" reads far fewer files than "fix the login bug."

Claude Code

  • Use /clear between tasks and /compact in long ones. Check usage with /usage.
  • Default to Sonnet; switch to Opus only for hard problems. Lower /effort for routine work.
  • Keep CLAUDE.md under 200 lines and move rarely needed instructions into skills, per Anthropic's docs.
  • Use plan mode before big changes, and subagents or hooks to keep noisy output out of the main context. Agent teams use about 7x the tokens of a single session, Anthropic says.

OpenAI Codex

  • Check what's left with /status. Keep AGENTS.md small and point Codex at specific files.
  • Fast mode uses 2.5x your included usage and Ultrafast 8x, per OpenAI. Leave them off unless you need the speed.
  • GPT-6 Luna's published range (350 to 3,000 messages per five hours on Plus) is about 20x GPT-6.1 Sol's, so use Luna for simple edits.

Cursor

  • Composer 2.5 costs about a third of Grok 4.7 per task on our estimate, so it stretches the weekly pool furthest.
  • Set a monthly cap on prepaid credit before you use Claude or GPT models on Premium and up.

GitHub Copilot

  • Use auto model selection: GitHub gives a 10% discount on it (30% on Max through Oct 28, 2026).
  • Completions and next edit suggestions are unlimited on paid plans and don't use credits, so lean on them for small edits.
  • Set a dollar budget so going over is a choice, and remember the reset is the 1st at 00:00 UTC, not your billing date.

Gemini CLI and Antigravity

  • In Gemini CLI, /stats model shows what you've used.
  • In Antigravity, Gemini and Claude/GPT models draw from separate pools. When one runs dry, switch families instead of waiting.
  • Leave AI Credit Overages on Never unless you want to pay per token.
  • On Pro, Gemini 4 Argon's quota only refills weekly. Save it for hard tasks and use Gemini 3.8 Flash for the rest.

FAQ

Which AI coding plan gives the most usage for $20?

Nobody publishes a like-for-like number, so there is no honest single winner. OpenAI is the only vendor that publishes ranges for its $20 plan: ChatGPT Plus gets an estimated 15 to 160 GPT-6.1 Sol local messages per five hours in Codex. GitHub publishes a dollar budget instead: Copilot Pro at $10 includes 1,500 AI credits (worth $15 at $0.01 each) per month. Anthropic (Claude Pro $20) and Google (Google AI Pro $19.99 in Antigravity) publish only the reset rhythm, not the size of the allowance. Cursor publishes multipliers (Premium is 4x Plus) but not the size of the Plus pool.

What happens when I hit my Claude Code limit?

Claude Code tells you whether you hit the five-hour session limit, the weekly limit, or a per-model (Opus or Sonnet) limit. You can wait for the reset, upgrade to Max, or turn on usage credits, which are billed at standard API rates. You can see your usage with /usage in Claude Code or under Settings > Usage.

Do Codex limits stop me mid-task?

OpenAI says that when you reach a limit the current turn can finish. After that you can wait for the reset, buy ChatGPT credits on Plus and Pro, or switch Codex to an API key and pay API rates. OpenAI says the price of credits can vary by account, region and plan, so it doesn't publish one price. Check your usage with /status.

When do GitHub Copilot AI credits reset?

At 00:00 UTC on the first day of every calendar month, whatever your billing date is. Unused credits don't roll over. If you run out you can upgrade (you pay only the price difference), set a dollar budget for additional usage at $0.01 per credit, or wait for the reset.

How much does one AI coding task cost?

It depends on the model and the size of the task, and no vendor publishes a per-task price. Our estimate, at published API prices, for a medium task (1.5 million input tokens, 90% of them cached, and 25,000 output tokens) is about $0.69 on Claude Sonnet 5.5, GPT-6.1 Sol or Gemini 4 Argon (before Dec 1, 2026), about $1.37 on Claude Opus 5.5, and about $1.13 on Grok 4.7 in Cursor. Anthropic says the average Claude Code cost is about $13 per developer per active day. Hard tasks cost more: on Artificial Analysis's Coding Agent Index (checked Oct 29, 2026), Claude Code with Opus 5.5 averaged $11.42 a task at API prices on about 14.5 million tokens, and Codex with GPT-6.1 Sol $1.50. These are estimates; your token counts will differ.

Does Copilot Pro include Claude Opus 5.5?

No. GitHub's plans page lists Claude Opus 5.5 on Copilot Pro+, Max, Business and Enterprise, not on Copilot Pro. Copilot Pro at $10 includes Claude Sonnet 5.5, Sonnet 5 and Haiku 5.5, among others.
