ChatGPT Pro Codex limits: the Oct 30 cut is off (what changed, what to do)

Short answer: if you saw posts saying ChatGPT Pro $200 gets half the Codex usage starting Oct 30, that's out of date. On Oct 29, OpenAI canceled the Pro 200 reduction and doubled the Work and Codex allowance on Pro 100 and Pro 500. Nobody on Pro loses usage today. Separately, since Oct 28, Pro and Business subscribers can claim $20 to $500 a month in free API credits, but most people won't get $500, and the credits don't add to your signed-in Codex allowance.

Checked Oct 30, 2026 on OpenAI's own pages: the Pro tiers help page, the ChatGPT release notes and the API credits help page. Anything that only shows up in posts or press is labeled reported.

How we got here

  • Sep 29: OpenAI launched Pro 500 ($500/mo, the only plan with Ultrafast) and reopened Pro 200 to new subscribers, saying "Included usage allowances are changing." Existing Pro 200 subscribers were emailed that they'd keep their old allowance through Oct 29 and then move to a lower one at the same price (reported; we haven't seen the email).
  • Oct 28: API credits for eligible Pro and Business subscriptions went live.
  • Oct 29: One day before the cut, OpenAI canceled it, doubled Pro 100 and Pro 500, and brought lower-allowance Pro 200 accounts up to the higher level. Dots keep separate, extended limits "for now."
  • Oct 30: Posts about the cut are still going around. They describe a plan that no longer exists.

Sources: ChatGPT release notes (Sep 29, Oct 29), ChatGPT Business release notes (Oct 28, Oct 29), gHacks on dots.

What to do now

  • On Pro 200 and planned to cancel over the cut? You can undo a scheduled cancellation any time before your billing period ends. You don't need to cancel and resubscribe to get the updated allowance, and resubscribing doesn't get you more than other Pro 200 subscribers.
  • Was Pro 200 only worth it for the old allowance? Look at Pro 100 again. It just doubled at $100, while a grandfathered Pro 200 account stayed where it was. OpenAI doesn't publish how big each allowance is, so check your usage dashboard (or /status in the Codex CLI) for a couple of weeks before you switch.
  • Claim your API credits. In ChatGPT, open Settings, then Billing, and find the API credits benefit. Your subscription has to be paid and at least 7 days old, and your ChatGPT and API accounts need the same email. The first grant is prorated, and unused credits expire at the end of each billing cycle, so a late claim this month gets you less.
  • Know what the credits can't do. OpenAI says they don't increase your ChatGPT or signed-in Codex allowance and aren't the same as ChatGPT usage credits. They pay for API usage in one linked API organization, subject to API rate limits.
  • Turn them into overflow anyway. Codex also runs with an API key, billed at API prices, and OpenAI says anyone can run extra local chats that way. Our reading: point Codex at a key from the organization that holds your credits and the grant covers it. OpenAI doesn't spell that combination out, so check your API usage page after the first run.
  • Stop burning allowance on speed. Fast mode uses your included allowance at 2.5x the Standard rate, and Ultrafast on Pro 500 at 8x. If you're running out, Standard is the easy fix.

What the credits buy, roughly Estimate

At API prices, our everyday medium task (a feature across 3 to 5 files) is about $0.69 on GPT-6.1 Sol, and Artificial Analysis measured $1.50 per hard benchmark task for Codex with GPT-6.1 Sol. So the $100 credit on Pro 100 is roughly 145 medium tasks or 66 hard ones, $200 is about 290 or 133, and $500 is about 725 or 333. Cheaper options if you're rethinking $200 a month

  • ChatGPT Plus, $20: same GPT-6.1 Sol in Codex, with a five-hour limit. OpenAI estimates 15 to 160 local GPT-6.1 Sol messages per five hours, plus weekly limits, and you can buy credits past that. Plus usage didn't change.
  • ChatGPT Business Premium seat, $125 ($100 billed annually): 5x a Standard seat, no five-hour limit, usage going up as of Oct 29, and $100 a month in API credits per seat. It needs a workspace of 2 or more users.
  • Codex with only an API key: no subscription. GPT-6.1 Sol is $2 in and $10 out per million tokens. Fine for light weeks, and it gets expensive on heavy ones.
  • Leaving OpenAI: Claude Max starts at $100 (5x Claude Pro) and also includes API credits. GitHub Copilot Pro is $10 with Claude Sonnet 5.5. Compare them in Claude Code vs Codex and Claude Code alternatives.

Our honest take: after Oct 29, Pro 100 is the plan most heavy Codex users should try first. Pro 200 only makes sense if your dashboard says you regularly use more than Pro 100 gives you.

FAQ

Is ChatGPT Pro $200 Codex usage being cut on Oct 30?

No. On Oct 29, 2026 OpenAI canceled the reduction it announced on Sep 29. Pro 200 accounts already on the higher Work and Codex allowance keep it, accounts on the lower one were doubled to match, and the price stays $200 a month.

Did OpenAI double every Pro plan?

Pro 100 and Pro 500 now get twice their previous Work and Codex allowance. On Pro 200, only the lower allowance doubled, so if you already had the higher one, your usage stays the same. Plus is unchanged, and Business Premium usage is increasing by an amount OpenAI hasn't stated.

Is Pro 200 really 20x Plus, and was it going to 10x?

OpenAI doesn't publish multiples for any Pro plan. The 20x and 10x figures come from subscriber emails quoted by users and press, and a reply on X saying Pro 500 is now 50x is reported, not on OpenAI's pages.

Who gets the free API credits, and how much?

Since Oct 28, 2026: Pro 100 gets $100 a month, Pro 200 $200 and Pro 500 $500. Business gets $20 per Standard seat and $100 per Premium seat, capped at $500 a month per workspace. Plus, free trials, Enterprise and Edu don't qualify, and the subscription has to be at least 7 days old.

Do the API credits give me more Codex usage?

Not in signed-in Codex. OpenAI says the credits don't increase your ChatGPT or signed-in Codex allowance. They pay for API usage in one linked API organization, and Codex run with an API key bills at API prices, which is how they can work as overflow. Unused credits expire each billing cycle.

Should I switch from Pro 200 to Pro 100 now?

Maybe. Pro 100 just doubled at $100, while a Pro 200 account that already had the higher allowance didn't change. OpenAI doesn't say how the two compare in size, so check your usage over a couple of weeks first. That's our opinion, not OpenAI guidance.
