What one AI coding task really costs (Oct 2026)

Short answer: an everyday task, like adding a feature across a few files, is usually under $1.50 at API prices, by our estimate. A hard task is a different story. Artificial Analysis ran 290 tough benchmark tasks through each coding agent and measured $11.42 a task for Claude Code with Opus 5.5, $13.30 with Sonnet 5.5, $11.73 for Antigravity CLI with Gemini 4 Argon and $1.50 for Codex with GPT-6.1 Sol. The thing that moves the bill most isn't the price per token. It's how many tokens the agent burns to finish.

Benchmark figures from Artificial Analysis's Coding Agent Index v2.0 and API prices from each vendor's pricing page, all checked Oct 29, 2026. Anything we worked out ourselves is labeled as an estimate.

Why our estimate says $0.69 and the benchmark says $11.42

Our usage limits page prices a medium task (a feature across 3 to 5 files, with tests) at about $0.69 on Sonnet 5.5 and $1.37 on Opus 5.5. That's not wrong, it's a smaller task. Here's the gap, piece by piece:

  • Task size, by far the biggest part. Our medium task assumes about 1.5M tokens. The benchmark tasks averaged 3.2M to 27.2M depending on the setup, and 14.5M for Claude Code with Opus 5.5. That's about 10 times our medium task.
  • Per token, the math lines up. Claude Code with Opus 5.5 came out at $0.79 per million tokens on the benchmark. Our estimate works out to $0.90, a bit higher because we assumed 90% of input is cached and Artificial Analysis measured 95%. Codex with GPT-6.1 Sol: $0.38 measured vs $0.45 in our math. So the per-token pricing isn't the problem. The token count is.
  • Max effort. Most setups ran at max or high effort, which means more thinking tokens. Your default may be lower.
  • Long, chatty runs. Claude Code with Opus 5.5 averaged 146 turns and an hour per task. Codex with GPT-6 Astra averaged 39 turns and 25 minutes. Every turn resends the context.
  • Cache writes. Artificial Analysis counts them. We left them out, so our numbers run a little low on Claude.
  • API price, not plan price. On Claude Pro or Max, ChatGPT Plus or Google AI Pro you don't pay this per task. It comes out of your allowance instead.

Our take: keep using $0.10 to $1.40 as the cost of an everyday task, and budget roughly $1.50 to $13 at API prices for a hard, hour-long one, depending a lot on the agent and model.

Three things that surprised us

The cheaper Claude model cost more

Claude Sonnet 5.5 is half the price of Opus 5.5 per token. But on these tasks Claude Code with Sonnet 5.5 used 24.1M tokens to Opus's 14.5M, took longer (1.3 hours vs 1.0) and cost more ($13.30 vs $11.42), with a lower score. On hard work, Opus can be the cheaper pick.

Same list price, 9x the bill

GPT-6.1 Sol and Claude Sonnet 5.5 both list at $2 in and $10 out per million tokens. Codex with Sol finished tasks on 3.9M tokens for $1.50. Claude Code with Sonnet used 24.1M and cost $13.30. That's different agents as well as different models, so it isn't a pure model test, but it shows how much the agent's habits matter.

Haiku 5.5 isn't as cheap as it looks

Claude Haiku 5.5 lists at $0.10 in and $0.50 out, the same as GPT-6 Luna. But Anthropic bills any request with a prompt over 100,000 tokens at 5x that ($0.50 / $2.50), and agent sessions pass 100K fast. On the benchmark, Claude Code with Haiku 5.5 cost $2.67 a task. Codex with Luna cost $0.16.

Haiku's two-tier pricing is on Claude API pricing. OpenAI also doubles GPT-6 input prices above 272K tokens (OpenAI API pricing).

A note on Gemini 4 Argon's $11.73

Google's API price for Gemini 4 Argon is $2 in and $10 out per million tokens through Nov 30, 2026, then $4 and $20 from Dec 1. Artificial Analysis says it uses current API pricing, but its $11.73 is almost exactly double the $5.86 an earlier snapshot of the index showed for the same 13.9M tokens, which matches the Dec 1 price. Our read: through Nov 30, the same run would cost about half on the API. Artificial Analysis doesn't spell out which price it used, so treat that as our inference.

In Antigravity itself you don't pay per token. Google AI Pro ($19.99) includes Argon, but on Pro it has its own weekly-only quota, with no five-hour refresh. See Cursor vs Antigravity for the rollout and limits.

Sources: Gemini API pricing, Google's Gemini 4 Argon announcement, and the earlier index snapshot as archived by aicharts.io (retrieved Oct 27, 2026), all checked Oct 29, 2026.

How to cut your cost per task

  • Don't default to max effort. On the benchmark, Codex with GPT-6.1 Terra scored 48 at xhigh for $0.69 a task and 48 at max for $1.24. Same score, almost double the cost. At low effort it was $0.20 with a score of 35.
  • On hard tasks, try the bigger model. Opus 5.5 finished in fewer tokens than Sonnet 5.5 and cost less per task.
  • Start fresh for each task. Every turn resends the conversation, so long sessions with old history pile up input tokens.
  • Watch long prompts on small models. Haiku 5.5's price jumps 5x past 100K tokens, and GPT-6 input doubles past 272K.
  • Watch Claude Code background agents. While a background agent is running, Claude Code resends its full transcript about every 30 seconds to write a short status line (agent_summary). Users measured 16% to 26% of their spend going to it; Anthropic says it's about 2% of cost on average, and about 6% in the terminal. Anthropic shipped a cache fix in 2.1.311 and is working on a cheaper mode, but there's no supported off switch yet. Fewer background agents running at once is the practical fix.
  • Use a plan for heavy days. If you regularly run hour-long agent sessions, a subscription allowance is usually cheaper than paying API rates per task.

Terra figures from Artificial Analysis: Claude Code vs Codex, checked Oct 29, 2026. Background agent figures from GitHub issue #86879 and the Hacker News thread with Anthropic's reply, checked Oct 30, 2026.

FAQ

How much does one AI coding task cost?

At API prices, an everyday task like a feature across 3 to 5 files is about $0.69 on Claude Sonnet 5.5 or GPT-6.1 Sol and about $1.37 on Claude Opus 5.5, by our estimate. Hard tasks cost much more: on Artificial Analysis's Coding Agent Index (checked Oct 29, 2026), Claude Code with Opus 5.5 averaged $11.42 a task, Claude Code with Sonnet 5.5 $13.30, Antigravity CLI with Gemini 4 Argon $11.73 and Codex with GPT-6.1 Sol $1.50.

Why does Artificial Analysis say a Claude Code task costs $11.42?

Because its tasks are big. They are hard benchmark tasks (real repo changes graded on whether a maintainer would merge them, terminal tasks and code Q&A), run at max effort, and Claude Code with Opus 5.5 averaged 14.5 million tokens, 146 turns and about an hour per task. That is about 10 times our medium task. Per token, the cost is close to our math: $0.79 per million tokens measured vs $0.90 in our estimate. The figure is at API prices, not a Claude plan price.

Is Claude Sonnet 5.5 cheaper than Opus 5.5 per task?

Per token, yes, it's half the price. Per hard task, not on Artificial Analysis's benchmark: Claude Code with Sonnet 5.5 used 24.1 million tokens and cost $13.30 a task, while Opus 5.5 used 14.5 million and cost $11.42, with a higher score.

Which coding agent is cheapest per task?

Among strong setups on Artificial Analysis's index, Codex with GPT-6.1 Sol: a score of 54 for $1.50 a task. Cheaper options score lower, such as Codex with DeepSeek V4.1 Flash (47, $0.39) or GPT-6 Luna (31, $0.16). Checked Oct 29, 2026.

Do I pay these prices on a Claude, ChatGPT or Google AI subscription?

No. Those figures are pay-per-token API prices. On Claude Pro or Max, ChatGPT Plus or Google AI Pro, usage comes out of your plan's allowance. You pay API rates when you use your own API key (for example in Cline, Kilo Code, OpenCode or Aider), buy Claude usage credits past your limit, or use a Codex API key.

How much does Gemini 4 Argon cost per task?

Artificial Analysis lists $11.73 a task for Antigravity CLI with Gemini 4 Argon (high), on 13.9 million tokens. That looks like Google's standard price of $4 in and $20 out per million tokens, which starts Dec 1, 2026; through Nov 30 the API price is half that. In Antigravity, Google AI Pro ($19.99) includes Argon on a separate weekly-only quota.
