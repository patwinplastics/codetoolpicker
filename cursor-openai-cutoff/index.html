GPT in Cursor after Nov 12: what stops working, and 4 ways to keep OpenAI models

Short answer: OpenAI is ending its deal to supply models to Cursor, with a proposed shutoff date of Nov 12, 2026 (one week from today). The date isn't final and Cursor may cut access sooner. Cursor Tab isn't affected (it runs on Cursor's own models), but GPT in Agent, Chat, Auto, Cloud Agents and the CLI goes with the deal. You can keep GPT in Cursor's local Chat and Agent with your own OpenAI API key (Premium $30 or a legacy plan, not Plus), or skip Cursor's model picker and run the Codex extension inside Cursor on a ChatGPT plan. That second route is the cheapest way to keep GPT-6.1 Sol, which Cursor never got anyway.

Checked Nov 5, 2026 on OpenAI's announcement, OpenAI's Cursor help article, Cursor's Models & Pricing and API keys pages, OpenAI API pricing, Codex pricing and Copilot plans. Our own math is labeled as an estimate.

Our pick for most people

  • You're on Cursor Plus ($8) and like GPT: add ChatGPT Plus ($20) and run the Codex extension. $28 a month gets you Cursor with Grok and Composer plus GPT-6.1 Sol through Codex. Your own API key isn't an option on Plus.
  • You're on Premium or a legacy plan and use GPT in Agent a lot: try your own OpenAI key on a test project now, and check which GPT models the picker actually shows you. If the model you want isn't there, use the Codex extension instead.
  • You use GPT in Cloud Agents, Automations or the CLI: no key fixes those. Switch those jobs to Grok 4.7 or Composer 2.5, move them to Claude or Gemini on Premium, or run them in Codex cloud tasks.
  • GPT is the main reason you pay for Cursor: it's a good moment to compare Codex vs Cursor honestly. Cursor never got GPT-6 and won't get future OpenAI models.

Do this before Nov 12

  1. Write down which GPT models you pick in Cursor, and where: local Agent and Chat, Auto, Cloud Agents, Automations or the CLI.
  2. For local work, set up your route now: an OpenAI key (Settings > Models, Premium or legacy plans) or the Codex extension (Command Palette: "Codex: Open Codex Sidebar"). Test it on a throwaway repo.
  3. If you use an API key, set a monthly spend limit in your OpenAI account first.
  4. Move Cloud Agents and Automations that use GPT to a model Cursor will keep, and re-check the results once.
  5. Keep a non-OpenAI model enabled as a fallback, because Cursor can end access before Nov 12.
  6. Teams: check whether your admin allows personal API keys, and whether your Zero Data Retention needs rule out your own key (Cursor's ZDR doesn't cover it).

What we couldn't confirm

  • The final date. Nov 12 is OpenAI's proposed date. Neither company has published a confirmed one.
  • Whether Cursor has a replacement deal. Cursor said in September it would share more "in the coming weeks." We found nothing newer on Cursor's own pages.
  • Which GPT models work with your own key. Cursor's page says OpenAI keys support "standard, non-reasoning chat models" and that the picker shows which are available. GPT-6.1 Sol and GPT-5.6 Sol are reasoning models, so check your picker before you count on them.
  • Whether past chats that used GPT keep working. Not addressed by either company. Expect to switch models mid-thread.

FAQ

When does Cursor lose OpenAI models?

OpenAI proposed Nov 12, 2026 as the shutoff date when it announced on Aug 28 that it would wind down its contract with Cursor after SpaceX bought it. As of Nov 5 the date is still called proposed, OpenAI says Cursor may end access sooner, and no confirmed date has been published.

Will Cursor Tab stop working on Nov 12?

No. Cursor says Tab completion uses Cursor's built-in models, so it isn't affected. What loses GPT is Agent and Chat (unless you add your own key), Auto routing, Cloud Agents, Automations, the Cursor CLI and Cursor's API and SDK.

Can I use my own OpenAI API key in Cursor after the shutoff?

Yes for local Chat and Agent, on Premium ($30) and up or a legacy plan. Cursor Plus ($8) doesn't allow your own API keys. You pay OpenAI's API prices directly. Cursor's page says OpenAI keys support standard, non-reasoning chat models and the picker shows which are available, so check that the model you want appears.

Can I use my ChatGPT subscription for GPT in Cursor?

Not in Cursor's own model picker, because a ChatGPT plan doesn't include API usage. But you can install OpenAI's Codex extension in Cursor and sign in with ChatGPT. On Plus ($20) that includes GPT-6.1 Sol and Terra, in a separate Codex panel.

Does my own API key work in Cursor Cloud Agents?

No. OpenAI and Cursor both say your own key and gateway credentials don't apply to Cloud or Background Agents, Automations, Auto, Tab, the CLI or Cursor's API and SDK. Those jobs need a model Cursor supplies, like Grok 4.7, Composer 2.5, Claude or Gemini.

Is GPT more expensive outside Cursor?

Usually cheaper. Cursor's newest OpenAI model is GPT-5.6 Sol at $4 input and $20 output per million tokens, about $1.64 for our medium task estimate. GPT-6.1 Sol on OpenAI's API is $2 and $10, about $0.69 for the same task, and it's included in ChatGPT Plus through Codex up to the plan's limits.
