Claude Fable 5.2 vs Opus 5.5 in Claude Code: is the new model worth 2x?

Short answer: keep Opus 5.5 as your default and pick Fable 5.2 at the start of a session for the hard, long, fuzzy jobs: a bug nobody can pin down, an outage, an architecture call, a migration you'd normally split into ten tickets. Fable costs twice as much per token ($8/$40 per million vs $4/$20), and Anthropic itself says to start on Opus. If you're on Claude Pro, try Fable now: it's included in your plan only until Nov 16, 2026 at 11:59 PM PT, then it goes back to pay-as-you-go credits. On Max and Ultra it stays included for up to half your weekly limit. And don't switch models mid-session: you lose the cache and pay to re-read the whole conversation.

Checked Nov 11, 2026 on Anthropic's Fable 5.2 announcement (Nov 9), Anthropic API pricing, Fable 5.2 launch offers, Fable models on your plan, Claude Code model configuration, the GitHub changelog and Cursor's Fable 5.2 docs. Benchmarks are Anthropic's and Cursor's own numbers, labeled as such.

  • Optional fast mode: up to 2.5x faster at $16 and $80 per million. In Claude Code it needs usage credits on subscription plans.
  • Claude Code 2.1.321 is the first version that runs it. The fable alias now means Fable 5.2, and best now means the same as opus.
  • Also live the same day in GitHub Copilot (Pro+ and up) and Cursor.

The mid-session switch trap

Each model has its own prompt cache. When you run /model fable halfway through a long Claude Code session, the next request re-reads the whole conversation with no cache hits. On a 400,000-token conversation that's about $3.20 at Fable's input price (or $4.00 at the cache-write rate), versus about $0.08 to read the same tokens from cache. On a subscription, that's a chunk of your limit instead of dollars.

Fast mode has the same catch: the first time you turn it on in a conversation, the whole context bills once at the uncached fast price, $16 per million on Fable (about $6.40 for 400,000 tokens).

Pick the model when you start the session. If you want Fable for planning only, start a fresh session for it and hand the plan to an Opus session afterwards.

How to switch Claude Code to Fable 5.2

  1. Update: claude update, then claude -v. You need 2.1.321 or later.
  2. Pick it at the start: /model fable or claude --model fable. In the picker, press s to use it for this session only; Enter saves it as your default for every new session, which is easy to forget.
  3. Pin it if you need to: the full ID claude-fable-5-2 won't move when the next Fable ships.
  4. Watch billing: if the Fable row says "Requires usage credits," it bills credits, not your plan. In non-interactive -p runs and Agent SDK apps that don't show the prompt, Claude Code bills those credits without asking. Check scripts and CI before Nov 16 if you're on Pro.
  5. Fix best: if your settings or scripts use best, they now run Opus 5.5, not Fable.
  6. Teams: admins can allow or block it with availableModels in managed settings; claude-fable-5 permits 5, 5.1 and 5.2.

Saved claude-fable-5-1 picks move to Fable 5.2 automatically on Pro, Max and Ultra the first time you run 2.1.321. Console accounts, third-party providers and project or managed settings keep 5.1. Source: Claude Code model configuration.

Fable 5.2 outside Claude Code

  • GitHub Copilot: in VS Code, Visual Studio, JetBrains, Xcode, Eclipse, Copilot CLI, the coding agent and github.com, on Pro+, Max, Business and Enterprise. Billed at provider list price under usage-based billing. Gradual rollout. Copilot Pro+ at $39 gives about $70 of credits, so if you want occasional Fable runs and already use Copilot, that's a cheaper door than Claude Max.
  • Cursor: on by default for personal and Team accounts with Privacy Mode off. Bills $8 and $40 per million on top of your plan. When a request trips Fable's guardrails, Cursor quietly routes it to Opus. Cursor recommends starting at high effort, and says not to carry over your Fable 5.1 setting.
  • Data retention: every Fable model requires Anthropic to keep prompts and outputs to run its safety classifiers (not for training). That's why Copilot Business/Enterprise and Cursor Privacy Mode need an opt-in. Eligible enterprises get a zero data retention exemption through the end of 2026.

FAQ

Is Claude Fable 5.2 free on Claude Pro?

Only this week. Anthropic's launch offer includes every Fable model in Pro plans and standard Team seats until Nov 16, 2026 at 11:59 PM PT (2:59 AM ET on Nov 17), for up to 50% of your weekly usage limit, plus one Fable limit reset if your paid billing was in place before Nov 9. After that, Fable on Pro runs on pay-as-you-go usage credits again.

Is Fable 5.2 included on Claude Max and Ultra?

Yes. On Max ($100), Ultra ($200) and premium Team seats, Fable models are a standard part of the plan for up to 50% of your weekly limits, and they use those limits faster than other Claude models. The launch offer adds one to three Fable limit resets depending on how long you've subscribed, and they expire Mar 8, 2027.

How much does Fable 5.2 cost compared with Opus 5.5?

On Anthropic's price list, Fable 5.2 is $8 per million input tokens and $40 per million output, twice Opus 5.5 ($4 and $20). Cache reads are the exception: $0.20 per million on both. Fable 5.2 is 20% cheaper than Fable 5.1, which was $10 and $50.

Should I switch Claude Code from Opus 5.5 to Fable 5.2?

Not as your default. Anthropic itself tells most people to start on Opus 5.5 and move up to Fable for open-ended, long-running work: root-cause investigations, outage debugging, architecture decisions and big tasks you'd normally split up. For a clear, scoped feature, Opus 5.5 is half the price per token.

Which Claude Code version do I need for Fable 5.2?

Version 2.1.321 or later. Run claude update, then claude -v. Older versions fail with "Claude Code does not support this model." Then run /model fable at the start of a session.

Why does /model best give me Opus now?

From Claude Code 2.1.321, the best alias points at the same model as opus, which is Opus 5.5 on the Anthropic API. If you typed best to get the strongest model, you now get Opus. Use /model fable or the full ID claude-fable-5-2 instead.

Can I use Fable 5.2 in Copilot or Cursor instead?

Yes, but you pay list price either way. GitHub Copilot has it on Pro+ ($39), Max, Business and Enterprise at provider list pricing from your AI credits, not on Pro $10. Business and Enterprise admins have to turn its policy on. Cursor bills it at $8 and $40 per million on top of your plan, not from included usage. Both require Anthropic's data retention for Fable.
