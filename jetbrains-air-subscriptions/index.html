JetBrains Air: which AI subscription should you bring?

Short answer: if you work in IntelliJ, PyCharm, WebStorm or another JetBrains IDE and don't pay for an AI plan yet, GitHub Copilot Pro at $10 is now the cheapest way to run an agent in Air. Since Nov 3 it runs on your Copilot plan, and $10 buys about $15 of model usage (1,500 AI credits) versus about $10 on JetBrains AI Pro. Already pay for ChatGPT? Codex in Air uses your plan. Already pay for Claude? It only works in Air's terminal tab, not the chat panel. Cursor needs a paid Cursor plan. Skip JetBrains AI unless you want Junie, cloud runs on JetBrains credits, or one JetBrains bill. One catch with Copilot: Air can't show or cap your Copilot usage, so tasks just fail when credits run out.

What changed on Nov 3

Air is JetBrains' agent workspace. Inside your JetBrains IDE you hand tasks to coding agents, run several at once (in separate sessions or Git worktrees), and review their diffs with JetBrains inspections and line comments. It works with Claude Agent, Codex, Gemini, GitHub Copilot and Junie out of the box, plus Cursor and others from the ACP agent registry.

On Nov 3, 2026, GitHub and JetBrains added GitHub Copilot as a built-in Air agent:

  • Local tasks in your IDE need Air and a Copilot subscription. No JetBrains AI plan and no Air Teams.
  • Cloud tasks run Copilot in a fresh, sandboxed VM through Air Teams and also bill to your Copilot plan, not JetBrains AI credits. You need a JetBrains account in an Air Teams business organization, and an admin has to turn Copilot on.
  • From JetBrains IDEs 2026.2.4, you can also pick Copilot as the provider for JetBrains' built-in Next Edit Suggestions.

Air Teams is only for JetBrains business customers right now. JetBrains says it plans to open it to individuals later, with no date, and that Air Teams on mobile arrives Nov 15.

What we couldn't confirm

  • Copilot Free in Air. JetBrains says Air accepts any plan GitHub allows for the Copilot CLI, and GitHub's plans page says every plan, Free included, has the CLI. We haven't tested Free in Air, and its credits are limited.
  • How long the flex credits last. About a third of Copilot Pro's 1,500 credits (and close to half of Pro+'s 7,000) are a "flex allotment" on top of the base. GitHub has said that part may change, so the $15 figure could shrink to $10.
  • Cloud billing for non-Copilot agents. Air's credits page says cloud tasks always spend JetBrains AI credits "whatever agent you pick," which predates the Copilot exception announced Nov 3. Expect Copilot cloud tasks on your Copilot plan and everything else on JetBrains credits.
  • Cloud compute charges. JetBrains says services in early access, including the compute behind cloud agents and automations, "may be available free of charge." No date for when that ends or what it will cost.
  • Junie Lite's end date. Free "for a limited time"; no date published.
  • Air Teams for individuals. JetBrains plans to expand access later; no date or price.

FAQ

Can I use my GitHub Copilot plan in JetBrains Air?

Yes, since Nov 3, 2026. Pick GitHub Copilot in Air's agent picker and sign in with GitHub. Local tasks in your JetBrains IDE run on your Copilot plan, not JetBrains AI credits. JetBrains says any plan GitHub accepts for the Copilot CLI works. Cloud tasks also bill to your Copilot plan, but they need Air Teams, which is only for JetBrains business customers right now.

Do I need a JetBrains AI subscription to use Air?

Not for local sessions. You can sign in with Copilot, a ChatGPT plan for Codex, a paid Cursor plan, Claude Code in the terminal, or an API key. JetBrains says a JetBrains AI subscription is currently required for cloud runs, and Junie Lite is free for a limited time with just a JetBrains Account.

Can I use my Claude Pro or Max subscription in JetBrains Air?

Only by running Claude Code in Air's terminal surface (a full-screen editor tab). The graphical Claude Agent chat can't sign in with a Claude subscription: it needs JetBrains AI or an Anthropic API key with API billing. JetBrains support says Anthropic doesn't allow third-party apps to sign in with a claude.ai account.

Does my ChatGPT plan work with Codex in Air?

Yes. JetBrains support says Codex in Air accepts a ChatGPT Plus, Pro or team plan through Codex's own login, shown as "Managed by Codex." Usage counts against your normal Codex limits.

Is Copilot Pro or JetBrains AI Pro better value at $10?

For agent work, Copilot Pro. Both cost $10 a month. JetBrains AI Pro includes 10 AI credits, and JetBrains says one credit is $1 of model usage, so about $10. Copilot Pro includes 1,500 AI credits at $0.01 each, so about $15 of usage, plus Copilot's own completions. Pick JetBrains AI if you want Junie, cloud runs on JetBrains credits, or one bill managed by JetBrains.

Can Air warn me before my Copilot credits run out?

No. JetBrains and GitHub both say Air can't show or cap Copilot usage. Air checks that you have a Copilot subscription, but if your credits are gone the task just fails. Watch usage and set budgets on GitHub instead.

Should I use Copilot in Air or the Copilot plugin?

Use both if you like; they share one subscription. GitHub calls the plugin the complete experience: inline chat, Copilot code review, commit messages, agent customizations, a local sandbox and enterprise controls. Air is the lighter option for handing off tasks, running several agents side by side, and reviewing their diffs in one place.
