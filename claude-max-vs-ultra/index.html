Claude Max vs Ultra: is $200 worth it now? (And every other $100 vs $200 coding plan)

Short answer: on Oct 30, 2026 Anthropic turned Max 20x into Ultra ($200). Ultra gives you 2x Max's weekly usage (10x Pro vs 5x Pro) and, once your account is verified, no five-hour limit. So it's worth it if you hit Max's weekly cap or keep hitting the five-hour wall in the middle of long Claude Code runs. If you only hit the wall now and then, Max at $100 plus usage credits is cheaper. And across other tools, doubling from $100 to $200 buys anywhere from 2x to 4x more usage, depending on who you pay.

Checked Nov 4, 2026 on each vendor's own pages: Claude pricing, Claude Ultra help article, Claude API credits docs, ChatGPT Pro tiers, Codex pricing, Copilot plans, Cursor (X Subscription) pricing, Google AI plans, Antigravity plans, Kiro billing and Devin pricing. Our own math is labeled as an estimate.

New Nov 11, 2026: Claude Fable 5.2 is out at twice Opus 5.5's per-token price. Claude Pro gets it free only until Nov 16; Max and Ultra get it for up to half the weekly limit. Fable 5.2 vs Opus 5.5: when it's worth it.

What actually changed for Max 20x people

  • The headline number went from "20x" to "10x". That's not a cut on its face: the old 20x was per five-hour session, the new 10x is per week. Anthropic doesn't publish either allowance as a number, so nobody outside Anthropic can say for sure whether a week of work fits in more or less than before. Watch Settings > Usage for a couple of weeks before you decide.
  • The five-hour wall is gone once you're verified. Check Settings > Usage: if there's no "Current session" bar, you're verified. Anthropic says verification is automatic, based on account and payment history, and verifying your phone at checkout doesn't count.
  • The weekly cap is now the only cap. That cuts both ways: you can burn a whole day on one huge refactor, but you can also burn half your week in that one day. There's also a separate weekly limit for Fable.

Sources: claude.com/pricing and What is the Ultra plan?, both checked Nov 4, 2026. Anthropic also says it may apply other caps "at our discretion" on every plan.

The API credit catch: Max's $100 and Ultra's $200 don't work in Claude Code

This is the part people get wrong. Max and Ultra now come with $100 or $200 a month of Claude Platform credits, but Anthropic's docs say they don't apply to interactive Claude Code (terminal, IDE, desktop or web) and can't pay for usage credits when you run out in Claude or Claude Code.

  • What they do cover: the Claude API, Message Batches, the Console Playground, Claude Managed Agents and the Claude Agent SDK.
  • How to claim: after 7 days on the plan, go to Settings > Billing on claude.ai and link a Claude Console organization. No card needed on the Console side.
  • Use it or lose it: credits refresh each billing cycle and expire at the end of it. No rollover.
  • Not on Bedrock, Vertex AI or Foundry. Only Anthropic's own platform.

A way to get value from them (our idea, an estimate): put the credits to work on jobs that don't need interactive Claude Code, like a nightly Agent SDK script that triages issues, a batch job that writes tests, or a PR summary bot. At our medium-task estimate, $100 is roughly 145 Sonnet 5.5 tasks a month, and $200 roughly 290. We couldn't confirm whether running claude -p with an API key counts as "interactive Claude Code" for this rule, so stick to the Agent SDK or API if you want to be sure.

OpenAI is different here. ChatGPT Pro also includes $100, $200 or $500 a month in API credits. They don't add to signed-in Codex usage either, but Codex can run with an API key at API prices, so they can act as overflow for Codex CLI work (details on our ChatGPT Pro Codex limits page).

Sources: Monthly API credits for Max, Ultra, and Team plans and Claude Platform docs, checked Nov 4, 2026.

What jumps out

  • Best step-up: Google AI Ultra (4x for 2x) and Cursor (3.3x for 2x). If you're already on their $100 tier and running out, the $200 tier is the better deal per dollar. With Cursor, remember Claude and GPT models aren't in that pool at all.
  • Claude is a straight 2x on the weekly cap. What you're really paying the extra $100 for is losing the five-hour limit.
  • Only two of these drop the five-hour window: Claude Ultra (verified accounts) and ChatGPT Pro (all three tiers, for now). Google AI Ultra still refreshes every five hours.
  • Copilot Max is the only $100 plan that tells you its allowance in dollars: $200 of AI credits a month. At our medium-task estimate that's about 290 Sonnet 5.5 tasks or 145 Opus 5.5 tasks (an estimate, assuming credits track API list prices). Half of it is the flex allotment, which GitHub says may change.
  • Kiro has no bulk discount. Every plan works out to $0.02 a credit, half the $0.04 add-on price. Pick the tier that matches your month; bigger tiers aren't cheaper per credit.
  • ChatGPT Pro is the only one with a $500 tier. Pro 500 adds Ultrafast mode, which uses your allowance at 8x the normal rate.

Who should pick what at $100 to $200

  • You live in Claude Code and the five-hour wall is the problem: Claude Ultra ($200). Nothing else gives you Claude Code with no five-hour window.
  • You want Claude Opus, but $200 feels steep: Copilot Max ($100, $200 in credits, Opus included) or Google AI Ultra $99.99 (Opus 5.5 in Antigravity). You lose Claude Code itself; see Claude Code alternatives.
  • You use OpenAI models and long sessions: ChatGPT Pro 100. No five-hour Codex limit right now, and its allowance doubled on Oct 29. Try it before Pro 200.
  • You use Cursor's own models (Composer, Grok) all day: Cursor Ultra ($200) gives the biggest step-up of the bunch at 50x Plus.
  • You want a hard monthly number: Kiro or Copilot. Both publish credits, so you can plan your month.
  • You're on the fence between two tools: splitting about $110 across two tools can beat $200 on one. For example, Claude Max ($100) for Claude Code plus Copilot Pro ($10) for completions and quick cloud tasks.

FAQ

What's the difference between Claude Max and Ultra?

Max is $100 a month with 5x Pro usage every five hours and every week, plus $100 a month in API credits. Ultra is $200 a month with 10x Pro usage per week, no five-hour limit for verified accounts, and $200 a month in API credits. Both include Claude Code and Fable up to half the weekly limit, and both are monthly only.

Is Claude Ultra the same as Max 20x?

It replaced it. On Oct 30, 2026 Anthropic renamed Max 20x to Ultra at the same $200 price and moved subscribers over automatically. The limit is now described as 10x Pro per week with no five-hour limit, instead of 20x Pro per five-hour session. Anthropic doesn't publish either allowance as a number.

Does Claude Ultra really have no usage limit?

No. Verified Ultra accounts have no five-hour limit, but there's still a weekly limit across all models and a separate weekly limit for Fable, and Anthropic says it may add other caps. New accounts keep a temporary five-hour limit until Anthropic verifies them automatically.

Can I use the Max or Ultra API credits in Claude Code?

No. Anthropic says the monthly API credits don't apply to interactive Claude Code in the terminal, IDE, desktop or web, and can't pay for usage credits in Claude or Claude Code. They work on the Claude API, Message Batches, the Console Playground, Managed Agents and the Claude Agent SDK, and expire each billing cycle.

Is Ultra worth $200?

It's worth it if you hit Max's weekly limit, or hit the five-hour limit most days. If you only hit the five-hour wall once or twice a week, Max at $100 plus usage credits at API rates is usually cheaper. That's our reading of Anthropic's plan rules, not Anthropic guidance.

Which $200 AI coding plan gives the most extra usage over its $100 tier?

By each vendor's own multipliers: Google AI Ultra goes from 5x to 20x Pro (4x for double the price), Cursor from Super 15x to Ultra 50x Plus (3.3x), and Claude and Kiro double (2x). Copilot has no $200 plan, and OpenAI and Devin don't publish multipliers. These multipliers only compare tiers within one tool.
