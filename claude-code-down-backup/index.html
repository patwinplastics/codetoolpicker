Claude Code is down? Here's your backup plan

Short answer: check status.claude.com first (status.anthropic.com serves the same page). If Claude Code or the Claude API is actually down, switch to a tool that can run a non-Claude model. The fastest option is whatever you already have signed in: Codex CLI if you have ChatGPT, Cursor or Copilot with a non-Claude model, Devin Desktop, Antigravity with Gemini, or Aider with an API key from another provider. Install that backup on a quiet day, not during the outage.

Checked Nov 15, 2026 against Anthropic's status page history for Nov 13, official pricing and docs for the backup tools, and Claude Code's memory docs. How to check status fast

  1. Open status.claude.com. status.anthropic.com served the same Claude Status page when we fetched both on Nov 15.
  2. Look at the components separately: Claude Code, Claude API (api.anthropic.com), and claude.ai. On Nov 13 they did not always fail together. A login problem can leave the API up; an API problem can take Claude Code with it.
  3. Read the latest incident, not just the colored dots. Anthropic posts updates in UTC. Eastern Time is UTC minus 5 in November (so 13:09 UTC is 8:09 AM ET).
  4. If you use Claude in another product, check that product's status too. We have not confirmed whether Cursor, Copilot or Antigravity's Claude models failed during the API incident, so treat any Claude path as possibly affected until you see it working.
  5. User-report sites such as Downdetector can hint that people are having trouble, but they are not a confirmation of cause or of which component is down. Use Anthropic's page as the source of record.

Local problem, or an outage?

  • The status page shows an open incident on Claude Code or the Claude API. It is not just you. Switch to a backup, or wait it out. During the 8:09 AM ET incident, anything talking to the Anthropic API was in the same boat, including Claude Code.
  • The status page is green, but Claude Code fails. Try claude.ai in a browser. If chat works and the CLI does not, it is more likely a local or CLI-only problem, or an incident that has not been posted yet. Restart the CLI, sign out and back in, try another network, and try a second machine if you have one.
  • Only one repo or one laptop fails. That is usually local: permissions, a bad config, a VPN or firewall, a sandbox, or a saved secret that no longer works. Our settings.local.json checker is worth a look if an allow rule might be the cause.
  • Login fails, but you already have an API key session open. On Nov 13 the morning incident was described as an authentication problem, and the Claude API was not listed as affected. An already authenticated API-key workflow might still have worked. We did not independently confirm that, and it would not have helped during the later API incident.

Keep a backup ready, before the next outage

  • Install a second CLI now and sign in once. Codex CLI is the closest terminal-shaped swap if you already pay for ChatGPT Plus or higher. Aider is the cheapest if you are willing to bring your own key. Devin CLI or Antigravity also work if that is already your other tool. The goal is that the next outage costs you a minute, not an account signup.
  • Keep a non-Anthropic API key (OpenAI, Gemini, or another provider Aider or your CLI already supports), with a spending cap you will notice. Do not paste that key into a chat, a ticket, or a settings.local.json allow rule. A second Anthropic key is not a backup for an API outage.
  • Put shared project rules in AGENTS.md. Claude Code's docs say it can read a repository's AGENTS.md in place of CLAUDE.md. Codex, Cursor and GitHub Copilot also read AGENTS.md. Gemini CLI uses GEMINI.md, so copy the same rules there if that is your Google backup. Keep the file short; these tools load it into every request.
  • Decide the non-Claude model in advance in Cursor, Copilot or Antigravity, so you are not hunting through a model picker while the clock is running.
  • Bookmark status.claude.com and, if you also rely on Codex, status.openai.com. Two status pages take less time than guessing.

FAQ

When was Claude Code down on Nov 13, 2026?

Two incidents, per status.claude.com. Logins to Claude.ai and Claude Code failed from 4:58 AM to 6:58 AM ET (09:58 to 11:58 UTC). Elevated errors on claude.ai, the Claude API and Claude Code ran from 8:09 AM to 10:38 AM ET (13:09 to 15:38 UTC). Anthropic has not published a root cause for either one.

How do I check if Claude Code is down?

Open status.claude.com. status.anthropic.com served the same page when we checked on Nov 15. Look at Claude Code, the Claude API and claude.ai separately, and read the incident updates. Timestamps are in UTC.

How can I tell a local problem from an outage?

An open incident on Claude Code or the API means it is not just you. A green status page plus a failure limited to one machine or one repo is more likely local. Try the website, another network, a restart, and a second computer before you assume a silent outage.

What is the fastest backup?

Whatever you already have signed in, as long as you can pick a non-Claude model. Codex CLI is the closest terminal swap. Cursor, Copilot, Devin Desktop, Antigravity and Aider are all fine if they are already set up. Starting from zero, Codex on a ChatGPT plan or Aider with an existing non-Anthropic key is usually quicker than buying and learning a new IDE in the middle of an outage.

Will Cursor or Copilot still work?

Possibly, if you use a non-Claude model. We have not confirmed how those products route their Claude models, so treat any Claude path as possibly affected when the Anthropic API is down.

Can I point Claude Code at another model during an outage?

Claude Code is a Claude product. During the Nov 13 API incident it was listed as affected alongside the API, so it is the wrong place to wait out an Anthropic failure. Use a different tool until the status page recovers.

How do I keep a backup ready?

Install a second CLI and sign in once, keep an API key at another provider with a cap, and store shared rules in AGENTS.md. Claude Code can read that file in place of CLAUDE.md.
