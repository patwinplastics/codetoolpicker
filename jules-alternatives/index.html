Jules is shutting down: where to move your background coding agent

Short answer: Google is winding down Jules. Nov 11, 2026 is the last day to finish sessions, then Jules goes read-only, and it shuts down on Dec 31, 2026. Google points people to Antigravity, but there's a catch: Antigravity doesn't run your agent on Google's machines yet, and it has no separate task pool like Jules did. If you want a hosted agent that keeps working with your laptop closed, the cheapest one we found is GitHub Copilot Pro at $10/mo. Codex (ChatGPT Plus) and Claude Code (Claude Pro) do it for $20.

Checked Nov 3, 2026 on each vendor's own pages: Jules turndown notice, Jules plans, Antigravity plans, Copilot plans, Codex pricing, Claude Code cloud docs, Cursor Cloud Agents docs and Devin pricing. Anything only reported elsewhere is labeled.

What survives and what doesn't

  • Your code is fine. Code, branches and pull requests already live in GitHub and stay there.
  • Jules-only stuff goes away unless you export it: account settings, environment variables, scheduled tasks, connected repos, memories, setup scripts, and every session's prompt, plan, activity log and patches.
  • How to export: Google's notice says to install Jules Tools (npm install -g @google/jules), run jules login, then paste Google's export prompt into a CLI coding agent such as Claude Code. It saves everything to ~/jules-export.
  • Careful with one file: the export includes env-variables.json with your real environment variable values. Keep that folder private and out of any repo.
  • No import on the other side. We found no tool, Antigravity included, that imports a Jules export. You'll copy the useful parts by hand (see moving your setup).

The Antigravity catch

Google's own line is that it's "bringing our learnings from Jules into Antigravity" to get "autonomous remote background task execution" (Google's post, quoted by The Verge). That's a plan, not a shipped feature. Here's what's true today:

  • No Google-hosted cloud runs. In a reply on Google's AI Developers Forum, Google says Antigravity "does not currently offer a turnkey, Google-hosted cloud sandbox" and that the request is logged with the product team. The workaround it suggests is running the Antigravity CLI on your own always-on Linux VM with agy remote-control start and steering it from antigravity.google. That VM is yours to pay for and keep secure. (forum thread, Remote Control docs)
  • No separate Jules-style allowance. Jules had its own task limits: 15 tasks a day and 3 at once on the free plan, 100 a day and 15 at once with Google AI Pro, 300 a day and 60 at once with Ultra (Jules plans page). In Antigravity, Google's forum reply says all agent work, including parallel subagents, draws from the same plan quota. So background work now competes with your normal coding.
  • Scheduled jobs do carry over, sort of. Antigravity Automations (previously called scheduled tasks) start agent conversations on a timer, on every plan. They run where Antigravity runs, so for "while I sleep" jobs you still need a machine that stays on.
  • Overages are opt-in. Pro and Ultra can buy AI credits for usage past the quota. Keep the AI Credit Overages setting on Never if you don't want surprise charges.

Our take: if you already pay for Google AI Pro and mostly used Jules for small chores, Antigravity is fine, especially if you have a home server or cheap VM to leave running. If you liked that Jules just ran somewhere else with nothing to babysit, Antigravity isn't that yet. This is our opinion, not Google guidance.

Unconfirmed: whether Google AI Pro or Ultra subscribers get anything back for losing Jules. A user asked on Google's forum; the reply explained the quota but didn't mention compensation. Google's pages don't say either way.

Our picks, by how you used Jules

  • "Fix this issue and open a PR" on GitHub: GitHub Copilot Pro ($10). You can assign work from an issue, and Agent Merge's "Watch and fix" can keep a PR green by fixing failing checks and merge conflicts. Cheapest hosted option we found.
  • Bigger tasks, best model quality per dollar: Codex on ChatGPT Plus ($20) or Claude Code on Claude Pro ($20). Both run in the vendor's cloud and let you pull the session back to your terminal (claude --teleport for Claude Code).
  • You already live in Cursor: Cloud Agents, but only from Premium ($30) up. They work with GitHub, GitLab, Bitbucket and Azure DevOps, which helps if you're not on GitHub.
  • Lots of parallel tickets from Slack, Linear or Jira: Devin Pro ($20) or Cursor Cloud Agents.
  • Recurring jobs (weekly dependency bumps, nightly triage): Claude Code cloud scheduled tasks, Copilot automations (eligible private and internal repos), or Antigravity Automations on a machine you keep on.
  • You were on Jules Free and want to stay at $0: honestly, there isn't a free hosted replacement among the big tools. Copilot Free doesn't get Copilot in the cloud, Codex Free is desktop-app only, Cursor Free and Plus don't include Cloud Agents, and Claude Code has no free plan. Antigravity Free works if your own computer does the running.

Want to build your own background agent?

Cursor's Agent SDK is now generally available (SDK 0.3.0, Oct 23, 2026, per its changelog). You define an agent as a folder of code, test it with evals, and run agent-sdk deploy to host it on Cursor or run it on your own infrastructure. Templates include a PR autofixer and a Linear or Jira triager, which covers a lot of what people used Jules for. FAQ

When does Jules shut down?

Google says Jules winds down on Dec 31, 2026. You can keep finishing sessions until Nov 11, 2026. After that Jules is read-only until the end of the year. Google's notice doesn't give an hour or time zone.

Will I lose my code when Jules shuts down?

No. Your code, branches and pull requests already live in GitHub and stay there. What you lose without an export is the stuff inside Jules: settings, environment variables, scheduled tasks, memories, setup scripts and session history. Google's export saves all of it to a local jules-export folder.

Is Google Antigravity a drop-in replacement for Jules?

Not yet. Google says it's bringing Jules-style remote background runs to Antigravity, but today Antigravity has no Google-hosted cloud sandbox, so agents run on your machine or a VM you keep on. It also has no separate task pool: background work uses the same plan quota as the rest of your Antigravity use.

What's the cheapest hosted replacement for Jules?

GitHub Copilot Pro at $10 a month. Paid Copilot plans get Copilot in the cloud, which works on a task in a cloud sandbox or GitHub Actions and opens a pull request. Model use comes out of 1,500 monthly AI credits. Codex on ChatGPT Plus and Claude Code on Claude Pro do the same for $20.

Is there a free alternative to Jules?

Not a hosted one from the big vendors, as of Nov 3, 2026. Copilot Free doesn't include Copilot in the cloud, Codex Free is desktop-app only, Cursor Free and Plus don't include Cloud Agents, and Claude Code has no free plan. Antigravity Free can run agents and automations, but on your own computer.

Can I import my Jules export into another tool?

We found no tool that imports it directly. Copy memories into your repo's AGENTS.md or CLAUDE.md, move setup scripts into the new tool's environment setup, put environment variables in its secrets store, and rebuild scheduled tasks one at a time.
