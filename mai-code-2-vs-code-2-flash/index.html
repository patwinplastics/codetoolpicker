Short answer: use Code 2 Flash for routine work (explanations, small edits, quick fixes) and MAI Code 2 for multi-file features and debugging. Keep a frontier model like Claude Opus 5.5 or GPT-6.2 Sol for the hardest, longest agent runs: Microsoft itself says these models are not yet tuned for very long-horizon agentic work.

The price is the story. In GitHub Copilot, MAI Code 2 costs $0.50 input / $2.50 output per million tokens, a quarter of GPT-6.2 Sol or Claude Sonnet 5.5 per token and an eighth of Opus 5.5. But that's a 50% launch promo. On May 17, 2027 every MAI Code 2 rate doubles, and Flash ends up the same per-token price as GPT-6 Luna and Claude Haiku 5.5. And on Copilot Pro ($10), MAI Code 2 is one of the few "Powerful" models you can pick at all.

Checked Nov 19, 2026 against the GitHub changelog (Nov 17), GitHub's Copilot models and pricing, supported models per plan, AI credit allowances, the legacy annual plan multipliers, Microsoft AI's launch post and the model card. Benchmark claims are Microsoft's, not our tests.

So the Flash discount vs Luna and Haiku is temporary. What stays: MAI models have a single rate in GitHub's table, with no long-context tier. Haiku 5.5 jumps to $0.50 / $2.50 over 100K input tokens and Luna to $0.20 / $0.75 over 272K, so on big-context requests Flash stays cheaper even after May. Per-token price isn't cost per task. A model that needs more turns or retries can cost more overall. Test on your own repo for a week before you switch your default.

Can you use it outside Copilot?
  • Microsoft Foundry: Code 2 Flash only, in limited-access preview, through the OpenAI-compatible Responses API. MAI Code 2 isn't in Foundry yet.
  • OpenRouter, Vercel, Hermes, OpenCode, Kilo: Microsoft says "soon." No date, no prices.
  • Cursor, Claude Code, Codex: not on Microsoft's list. If you want these models today, Copilot is the way. See Cursor vs Copilot.

What we couldn't confirm
  • Benchmarks. Every score and cost-per-task ratio is Microsoft's, run on its own eval platform, with MAI at promo prices. No independent coding-agent results yet.
  • Free and Student access. The changelog says Flash is available; plan docs say auto model selection only. We read that as Auto-only, but GitHub hasn't spelled it out.
  • The "annual plans" line. GitHub says both models are "available to eligible GitHub Copilot subscribers on annual plans" without saying who's eligible.
  • Third-party availability. No dates or prices for OpenRouter, Vercel, OpenCode or Kilo.
  • Pricing after the promo. GitHub publishes the May 17, 2027 rates; whether the promo gets extended is anyone's guess.

FAQ

5 questions

Should I use MAI Code 2 or MAI Code 2 Flash?

Use Code 2 Flash for explanations, small targeted edits and routine fixes, and MAI Code 2 for multi-file features, debugging, refactoring and UI work. Microsoft says neither is tuned yet for very long-horizon agent work, so keep a frontier model such as Claude Opus 5.5 or GPT-6.2 Sol for the hardest runs.

How much do MAI Code 2 and Code 2 Flash cost in GitHub Copilot?

Per million tokens, MAI Code 2 is $0.50 input, $0.025 cached input and $2.50 output, and Code 2 Flash is $0.05, $0.005 and $0.25. These are 50% promotional rates until May 17, 2027. From then, MAI Code 2 is $1, $0.05 and $5, and Flash is $0.10, $0.01 and $0.50. Usage is billed in GitHub AI Credits (1 credit = $0.01).

Which Copilot plans include MAI Code 2?

MAI Code 2: Copilot Pro, Pro+, Max, Business and Enterprise. Code 2 Flash: also Copilot Free and Student, where plan docs say models come through auto model selection only. On Copilot Pro ($10), MAI Code 2 is one of the few Powerful models available, since GPT-6.2 Sol, Claude Opus 5.5 and Gemini 4 Carbon need Pro+ or higher.

Is MAI Code 2 really cheaper than GPT-6.2 Sol and Claude Opus 5.5?

Per token, yes: at the launch promo it is a quarter of GPT-6.2 Sol and an eighth of Opus 5.5, and after May 17, 2027 it is half of Sol and a quarter of Opus 5.5. Microsoft's claim of 98% of GPT-6.1 Sol's performance at 40% of the cost, and 96% of Opus 5.5 at 5%, is its own benchmark with MAI at promo prices.

Can I use MAI Code 2 outside GitHub Copilot?

Not yet for MAI Code 2. Code 2 Flash is in a limited-access preview in Microsoft Foundry. Microsoft says both are coming soon to OpenRouter, Vercel, Hermes, OpenCode and Kilo, with no date. They are not offered in Cursor, Claude Code or Codex.
